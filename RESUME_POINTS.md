# AI Email Writer - Resume Points

## Project Overview
**AI-Powered Email Assistant System** - A comprehensive full-stack application that integrates artificial intelligence with email management, featuring a React web application, Chrome browser extension, and Spring Boot backend.

---

## Three Key Resume Points

### 1. **Full-Stack AI Integration Developer**
Developed a sophisticated AI-powered email assistant system integrating **Google Gemini API** with a complete full-stack architecture. Built using **React 19.1.1 with Material-UI** for the frontend, **Spring Boot 3.4.9 with WebFlux** for the backend, and a **Chrome Extension (Manifest V3)** for seamless Gmail integration. Implemented intelligent email reply generation with customizable tone settings (professional, casual, friendly) and real-time API communication using **Axios** and **WebClient**. Successfully deployed production-ready build system with **Vite** generating optimized 415KB bundle.

**Key Technologies:** React 19.1.1, Spring Boot 3.4.9, Google Gemini AI, Chrome Extensions, Material-UI, Maven, WebFlux, Vite

### 2. **Browser Extension & DOM Manipulation Expert**
Engineered a Chrome browser extension that dynamically integrates with Gmail's interface using advanced **DOM manipulation** and **MutationObserver API**. Implemented intelligent button injection that detects Gmail compose windows, extracts email content using multiple CSS selectors, and seamlessly inserts AI-generated responses into the compose box. Built with **Manifest V3** specifications including proper permissions, host permissions, and content script configurations.

**Key Technologies:** Chrome Extension APIs, DOM Manipulation, MutationObserver, Content Scripts, Gmail Integration

### 3. **Modern Frontend & Backend Architecture Specialist**
Architected a responsive web application using **React 19.1.1 with Vite** build tooling and **Material-UI** component library, featuring dynamic form handling, loading states, error management, and clipboard integration. Developed a robust REST API backend with **Spring Boot 3.4.9**, implementing reactive programming patterns with **WebFlux**, **Lombok** for code generation, and proper **CORS configuration** for cross-origin requests. Integrated external AI services with comprehensive error handling and JSON response parsing.

**Key Technologies:** React, Vite, Material-UI, Spring Boot, WebFlux, Lombok, REST APIs, Reactive Programming
